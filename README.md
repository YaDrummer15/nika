# 💜 История моих чувств к Николь

Персональный сайт-подарок, сделанный с любовью.

## 🚀 Запуск

Просто открой `index.html` в браузере или задеплой на GitHub Pages.

### GitHub Pages

1. Залей все файлы в репозиторий
2. Settings → Pages → Source: `main` branch, `/root`
3. Сайт будет доступен по адресу `https://username.github.io/repo-name/`

## 🔑 Пароли
